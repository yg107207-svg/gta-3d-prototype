# GTA 3D Prototype

Protótipo 3D (terceira pessoa) minimal — movimento do jogador, tiro básico e NPC com patrulha/perseguição.

Unity recomendado: 2022.3 LTS (ou similar). Este repositório contém scripts e instruções para montar a cena no Unity.

Arquivos adicionados:
- Assets/Scripts/PlayerController.cs
- Assets/Scripts/Weapon.cs
- Assets/Scripts/Projectile.cs
- Assets/Scripts/NPCPatrol.cs
- Assets/Scripts/NPCHealth.cs
- Assets/Scenes/SCENE_SETUP.txt
- README.md
- .gitignore

Próximos passos (rápido):
1. Abra o Unity Hub e crie um novo projeto 3D (Unity 2022.3 LTS recomendado).
2. Clone este repositório localmente ou copie os arquivos `Assets/Scripts/*` para `Assets/Scripts/` no seu projeto Unity.
3. Siga o `Assets/Scenes/SCENE_SETUP.txt` para criar a cena mínima e testar o protótipo.

Se quiser, eu posso também subir assets prontos (prefabs, cenas .unity) — confirme se quer que eu adicione arquivos de cena e prefabs diretamente no repositório.
